# Security policy

This file is the repository-level entry point for security implementation notes. It is not a certification, audit report, or vulnerability disclosure programme.

For the controls and limitations observable in source, see [docs/security/SECURITY.md](docs/security/SECURITY.md). The highest-priority repository gap is that Firestore rules, indexes, and Firebase deployment configuration are not tracked, so client-side data authorization cannot be assessed here.

No dedicated security-reporting channel or response-time commitment is configured in this repository. Do not include secrets, tokens, or personal data in a public report. The contact address in the application legal pages is not documented in source as a security-reporting channel.
